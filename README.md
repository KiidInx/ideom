# Flux Studio

**Die App, die Apps baut.** Beschreibe deine Idee, der KI-Agent schreibt
den Code, dein Handy kompiliert, packt, signiert und installiert die
fertige App — komplett auf dem Gerät.

Flux ist **kostenfrei, solange es in Entwicklung ist**.

- 🌐 Website: https://kiidinx.github.io/flux/
- 📰 Werkstatt-Meldungen: auf der Website und direkt in der App
- 🐛 Fehler gefunden oder Wunsch? → [Issues](../../issues)
- 💬 Fragen und Austausch → [Discussions](../../discussions)

Dieses Repository enthält die Website und die News-Quelle von Flux
Studio. Der Quellcode der App selbst ist (noch) nicht öffentlich.
